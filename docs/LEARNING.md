# LIVECORE Knowledge and Learning Experience

## Product direction

Documentation and training are integrated platform capabilities, not detached manuals.

## Knowledge system

- Versioned product and API documentation
- Generated references tied to released interfaces
- Contextual help inside role workspaces
- Troubleshooting flows and verified operational procedures
- Architecture decisions and traceable knowledge articles
- Localization with English as the baseline and community language packs
- Search that returns source, version and confidence context

## Learning system

- Role-based paths for FOH, monitor, performer, system technician, show-control operator and administrator
- Interactive tutorials and guided setup
- Realistic simulations for routing, show control, failover and incident exercises
- Assessments and verifiable competency records
- Training content aligned to the actual installed version and site profile

## AI-assisted knowledge

AI search and specialist agents may summarize or guide users only with source traceability, version awareness and clear uncertainty. They must not invent procedures or replace qualified judgment. Safety-critical instructions require expert review and approval before publication.

## Content lifecycle

Every operational article has an owner, version applicability, review date, evidence/source, approval status and change history. Obsolete instructions are withdrawn or clearly marked; content must not silently drift away from released software.
